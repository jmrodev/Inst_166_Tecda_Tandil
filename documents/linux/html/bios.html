¿Qué son BIOS, UEFI y Legacy (CSM)?

Estos términos se refieren a sistemas de arranque que permiten que tu computadora inicie el sistema operativo. Entender sus diferencias es clave para resolver problemas de instalación y compatibilidad.

BIOS (Basic Input/Output System)
💾

Sistema tradicional (desde los 80s) que realiza el POST (Power-On Self-Test) y carga el sistema operativo.

Características:

  • Interfaz textual (pantalla azul)
  • Usa MBR (Master Boot Record)
  • Límite de 2TB por disco
  • No soporta Secure Boot
  • Proceso de arranque más lento
UEFI (Unified Extensible Firm Interface)
🚀

Reemplazo moderno del BIOS (desde 2007) con mejor seguridad y rendimiento.

Características:

  • Interfaz gráfica (mouse compatible)
  • Usa GPT (GUID Partition Table)
  • Soporta discos >2TB
  • Secure Boot (protege contra malware)
  • Arranque más rápido (incluye "Fast Boot")
Legacy (CSM)
🔄

Modo de compatibilidad en placas modernas para emular BIOS tradicional.

Características:

  • Permite ejecutar sistemas antiguos
  • Necesario para algunos Windows 7/XP
  • Desactiva Secure Boot
  • También llamado CSM (Compatibility Support Module)

🔍 Comparación detallada

Característica BIOS (Legacy) UEFI
Interfaz Texto (teclado) Gráfica (mouse)
Tabla de particiones MBR (Master Boot Record) GPT (GUID Partition Table)
Límite de disco 2TB 9.4 Zettabytes (prácticamente ilimitado)
Número de particiones 4 primarias (o 3 + extendida) 128 particiones
Secure Boot No soportado Sí (bloquea sistemas no firmados)
Velocidad de arranque Lento (segundos de espera) Rápido (Fast Boot)
Compatibilidad Sistemas antiguos (Windows XP, 7) Requiere SOs modernos (Windows 8.1/10/11, Linux nuevo)

⚙️ Proceso de arranque comparado

Arranque Legacy (BIOS):

Power On (Encendido)
POST (Autocomprobación)
BIOS busca dispositivos booteables
Carga el MBR (primer sector del disco)
Ejecuta el bootloader (ej. NTLDR, GRUB)
Inicia el sistema operativo

Arranque UEFI:

Power On (Encendido)
POST (más rápido, en paralelo)
UEFI busca partición ESP (FAT32 con bootloaders)
Ejecuta el bootloader.efi (desde GPT)
Verifica Secure Boot (si está activo)
Inicia el sistema operativo (más rápido)

📌 ¿Cómo saber qué usa mi computadora?

En Windows: Abre "Información del sistema" (msinfo32) y busca Modo de BIOS .
En Linux: Ejecuta ls /sys/firmware/efi (si existe el directorio, es UEFI).

💡 ¿Cuál es mejor? ¿Cuándo usar cada uno?

Elige UEFI si:

  • Tienes un disco duro >2TB
  • Quieres Secure Boot (seguridad contra malware)
  • Usas Windows 10/11 o Linux moderno
  • Valoras arranque rápido

Usa Legacy (CSM) si:

  • Instalas Windows 7/XP
  • Tienes hardware muy antiguo
  • Usas herramientas de recuperación antiguas
  • El Secure Boot bloquea tu sistema

🔧 Ventoy y la compatibilidad

Ventoy es único porque soporta ambos modos en un mismo USB. Puedes:

  • Crear un USB que funcione en UEFI y Legacy simultáneamente
  • Elegir el modo al iniciar (automáticamente o manualmente)
  • Configurar Secure Boot si es necesario

Esto lo hace ideal para mantenimiento de equipos donde no sabes qué tipo de BIOS tendrá la máquina objetivo.
