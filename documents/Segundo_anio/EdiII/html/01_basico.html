Introducción al Shell de Linux

¿Qué es Bash?

Bash (Bourne Again SHell) es un programa intérprete de comandos para sistemas operativos Unix/Linux. Es una interfaz que permite al usuario interactuar con el sistema operativo mediante comandos de texto.

Cuando abres una terminal en Linux, normalmente estás usando Bash. Es como un intermediario entre tú y el sistema: escribes comandos, Bash los interpreta y luego el sistema los ejecuta.

¿Por qué Linux?

Linux es un sistema operativo de código abierto basado en Unix que ofrece diversas ventajas:

  • Libre y gratuito: No requiere licencias costosas
  • Seguro: Menor vulnerabilidad a virus y malware
  • Estable: Funciona por largos períodos sin necesidad de reinicio
  • Personalizable: Adaptable a diferentes necesidades y recursos
  • Transparente: Su código fuente es accesible y modificable

Terminales y Shells

La terminal es la ventana o aplicación que permite acceder al shell. El shell (como Bash) es el programa que interpreta los comandos que escribes y se comunica con el kernel de Linux para ejecutarlos.

usuario@linux:~$ echo "Hola, estoy usando Bash!" Hola, estoy usando Bash!

Cuando veas este símbolo $ o # en la terminal, significa que el sistema está esperando que ingreses un comando.

Comandos Básicos

pwd - Print Working Directory
🗂️

El comando pwd muestra la ruta completa del directorio actual donde te encuentras.

¿Por qué deberías conocerlo?

Es fundamental para orientarte en el sistema de archivos. Si te sientes perdido o necesitas confirmar dónde estás antes de realizar operaciones con archivos, pwd te da la ubicación exacta.

$ pwd /home/usuario/Documentos
Ejercicios para practicar:
  1. Abre una terminal y ejecuta pwd. Anota la ubicación.
  2. Cambia a otro directorio usando cd y vuelve a ejecutar pwd. ¿Qué diferencias notas?
  3. Ejecuta cd / y luego pwd. ¿Qué muestra ahora?
  4. Vuelve a tu directorio personal con cd ~ y verifica con pwd.
ls - Listar archivos
📁

El comando ls es uno de los más utilizados. Muestra el contenido de un directorio, permitiéndote ver qué archivos y carpetas existen.

¿Por qué deberías conocerlo?

Sin una interfaz gráfica, necesitas ls para "ver" lo que hay en tu sistema. Es como abrir el explorador de archivos pero en modo texto. Es el primer paso para interactuar con los archivos del sistema.

$ ls Documentos Imágenes Música Videos $ ls -l total 4 drwxr-xr-x 2 usuario usuario 4096 ene 15 10:30 Documentos drwxr-xr-x 2 usuario usuario 4096 ene 15 10:30 Imágenes drwxr-xr-x 2 usuario usuario 4096 ene 15 10:30 Música drwxr-xr-x 2 usuario usuario 4096 ene 15 10:30 Videos $ ls -a . .. .config Documentos Imágenes Música Videos

Opciones comunes:

  • -l: Muestra información detallada (permisos, tamaño, fecha)
  • -a: Muestra archivos ocultos (comienzan con .)
  • -h: Muestra tamaños en formato legible (KB, MB, GB)
  • -R: Lista recursivamente subdirectorios
Ejercicios para practicar:
  1. Lista los archivos de tu directorio home con ls.
  2. Usa ls -la para ver todos los archivos, incluyendo ocultos, con sus detalles. ¿Cuántos archivos ocultos encontraste?
  3. Ejecuta ls -lh /var/log. ¿Qué tamaño tienen los archivos más grandes?
  4. Intenta ls --color=auto. ¿Qué diferencias notas en la salida?
cd - Change Directory
🚶

El comando cd permite cambiar de un directorio a otro, navegando por el sistema de archivos.

¿Por qué deberías conocerlo?

La navegación es fundamental en cualquier sistema. Con cd puedes moverte entre carpetas para acceder a los archivos que necesitas. Es como caminar por los pasillos de una biblioteca para llegar a diferentes secciones.

$ cd Documentos $ pwd /home/usuario/Documentos $ cd .. $ pwd /home/usuario $ cd /etc $ pwd /etc $ cd ~ $ pwd /home/usuario

Atajos útiles:

  • cd ~: Ir al directorio home del usuario
  • cd ..: Subir un nivel (ir al directorio padre)
  • cd -: Volver al directorio anterior
  • cd /: Ir al directorio raíz del sistema
Ejercicios para practicar:
  1. Navega a tu directorio de Documentos (cd ~/Documentos) y verifica con pwd.
  2. Desde ahí, sube un nivel con cd .. y verifica dónde estás.
  3. Ve al directorio /etc y lista su contenido. Luego vuelve a tu home con un solo comando.
  4. Practica usando cd - para alternar entre dos directorios diferentes.
cat - Concatenar y mostrar archivos
📄

El comando cat (abreviatura de "concatenate") tiene múltiples usos: mostrar contenido, crear archivos y concatenar archivos.

¿Por qué deberías conocerlo?

Es la forma más básica de ver el contenido de archivos de texto. También permite crear archivos rápidamente y combinar varios archivos en uno. Es una herramienta esencial para manipular texto en la terminal.

# Mostrar contenido de un archivo $ cat archivo.txt Esta es la primera línea Esta es la segunda línea Esta es la tercera línea # Crear un nuevo archivo $ cat > nuevo.txt # Escribe el contenido y presiona Ctrl+D para guardar Este es un nuevo archivo Segunda línea ^D # Concatenar dos archivos en uno nuevo $ cat archivo1.txt archivo2.txt > combinado.txt $ cat combinado.txt Contenido de archivo1 Ahora viene el contenido de archivo2

Usos comunes:

  • Mostrar contenido: cat archivo.txt
  • Crear archivo: cat > nuevo.txt
  • Concatenar archivos: cat archivo1.txt archivo2.txt > combinado.txt
  • Mostrar con números de línea: cat -n archivo.txt
Ejercicios para practicar:
  1. Crea un archivo llamado notas.txt con cat > notas.txt y escribe algunas líneas.
  2. Visualiza el contenido de algún archivo de configuración: cat /etc/hostname
  3. Crea dos archivos de texto y luego concaténalos en un tercero.
  4. Utiliza cat -n archivo.txt para ver las líneas numeradas y cat -A archivo.txt para ver caracteres especiales.

Redirecciones Básicas

¿Qué son las redirecciones?

Las redirecciones son una característica poderosa de Bash que permite controlar dónde va la entrada y salida de los comandos. En lugar de mostrar resultados en pantalla, puedes enviarlos a archivos, o usar archivos como entrada para comandos.

Esta funcionalidad es fundamental para automatizar tareas y procesar grandes cantidades de información.

stdin, stdout y stderr
↔️

En Linux, todo es un archivo, incluso los flujos de entrada y salida de datos. Hay tres flujos estándar:

¿Por qué deberías conocerlo?

Entender estos conceptos es crucial para la automatización y el procesamiento de datos. Te permite controlar cómo los comandos reciben y producen información, permitiendo construir procesos complejos a partir de comandos simples.

# stdin (0): Entrada estándar (teclado) $ cat < archivo.txt Contenido del archivo # stdout (1): Salida estándar (terminal) $ echo "Hola" > salida.txt $ cat salida.txt Hola # stderr (2): Salida de error $ ls /directorio_inexistente 2> errores.txt $ cat errores.txt ls: cannot access '/directorio_inexistente': No such file or directory

Flujos estándar:

  • stdin (0): Entrada estándar, generalmente el teclado
  • stdout (1): Salida estándar, generalmente la terminal
  • stderr (2): Salida de error, también va a la terminal
Ejercicios para practicar:
  1. Crea un archivo con echo "Línea 1" > test.txt. Luego añade otra línea con echo "Línea 2" >> test.txt.
  2. Ejecuta un comando que produzca un error y redirige el error a un archivo: ls /noexiste 2> error.log
  3. Redirecciona tanto la salida normal como los errores: ls /etc /noexiste > salida.txt 2> errores.txt
  4. Envía tanto la salida normal como los errores al mismo archivo: ls /etc /noexiste > todo.log 2>&1
Operadores de Redirección
➡️

Bash proporciona varios operadores para controlar las redirecciones de entrada/salida.

¿Por qué deberías conocerlos?

Estos operadores son las herramientas que te permiten manipular los flujos de datos. Son esenciales para guardar resultados, filtrar información y crear scripts automatizados.

# > Redirección de salida (sobrescribe) $ ls > lista_archivos.txt $ cat lista_archivos.txt Documentos Imágenes Música Videos # >> Redirección de salida (añade) $ echo "Nueva línea" >> lista_archivos.txt $ cat lista_archivos.txt Documentos Imágenes Música Videos Nueva línea # < Redirección de entrada $ wc -l < lista_archivos.txt 5 # 2> Redirección de errores $ ls /noexiste 2> errores.log

Operadores principales:

  • >: Redirige salida (sobrescribe el archivo)
  • >>: Redirige salida (añade al final del archivo)
  • <: Redirige entrada
  • 2>: Redirige errores
  • &> o > archivo 2>&1: Redirige tanto salida como errores
Ejercicios para practicar:
  1. Practica la diferencia entre > y >>: Crea un archivo y luego añade contenido sin perder lo anterior.
  2. Crea un archivo de 10 líneas y usa sort < archivo.txt > ordenado.txt para crear una versión ordenada.
  3. Ejecuta find /etc -name "*.conf" > configs.txt 2> errores.txt para buscar archivos y separar resultados de errores.
  4. Crea un archivo que combine salida y errores: ls /bin /noexiste &> todo.log

Comandos de Visualización

head - Ver inicio de archivos
👆

El comando head muestra las primeras líneas de un archivo o entrada.

¿Por qué deberías conocerlo?

A menudo necesitarás echar un vistazo rápido a archivos sin verlos completos, especialmente si son grandes. head es ideal para esto, permitiéndote ver solo el principio, como revisar la primera página de un libro.

# Mostrar las primeras 10 líneas (comportamiento predeterminado) $ head /etc/passwd root:x:0:0:root:/root:/bin/bash daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin bin:x:2:2:bin:/bin:/usr/sbin/nologin sys:x:3:3:sys:/dev:/usr/sbin/nologin sync:x:4:65534:sync:/bin:/bin/sync ... # Mostrar las primeras 5 líneas $ head -n 5 archivo.txt Línea 1 Línea 2 Línea 3 Línea 4 Línea 5 # Mostrar las primeras 3 líneas de múltiples archivos $ head -n 3 archivo1.txt archivo2.txt ==> archivo1.txt <== Línea 1 Línea 2 Línea 3 ==> archivo2.txt <== Línea 1 Línea 2 Línea 3

Opciones útiles:

  • -n N: Muestra las primeras N líneas (por defecto 10)
  • -c N: Muestra los primeros N bytes
  • -q: No muestra nombres de archivos (en modo silencioso)
Ejercicios para practicar:
  1. Examina el inicio de un archivo de registro: head /var/log/syslog (puede requerir sudo)
  2. Muestra solo las primeras 3 líneas de tu archivo .bashrc: head -n 3 ~/.bashrc
  3. Compara el inicio de dos archivos diferentes: head /etc/hostname /etc/hosts
  4. Guarda las primeras 20 líneas de un archivo grande en otro archivo: head -n 20 /etc/services > servicios.txt
tail - Ver final de archivos
👇

El comando tail muestra las últimas líneas de un archivo o entrada.

¿Por qué deberías conocerlo?

Es crucial para monitorear logs y archivos que crecen continuamente. La opción -f es particularmente útil para administradores de sistemas, ya que permite ver actualizaciones en tiempo real, como vigilar la última página de un libro mientras alguien sigue escribiéndolo.

# Mostrar las últimas 10 líneas (comportamiento predeterminado) $ tail /etc/passwd nobody:x:65534:65534:nobody:/nonexistent:/usr/sbin/nologin systemd-network:x:100:102:systemd Network Management,,,:/run/systemd:/usr/sbin/nologin systemd-resolve:x:101:103:systemd Resolver,,,:/run/systemd:/usr/sbin/nologin messagebus:x:102:106::/nonexistent:/usr/sbin/nologin ... # Mostrar las últimas 5 líneas $ tail -n 5 archivo.txt Línea 6 Línea 7 Línea 8 Línea 9 Línea 10 # Seguir un archivo en tiempo real (útil para logs) $ tail -f /var/log/syslog [Continuará mostrando nuevas líneas a medida que se añadan]

Opciones útiles:

  • -n N: Muestra las últimas N líneas (por defecto 10)
  • -f: Sigue el archivo en tiempo real (follow)
  • -c N: Muestra los últimos N bytes
  • -q: Modo silencioso, no muestra nombres de archivos
Ejercicios para practicar:
  1. Examina el final de un archivo de configuración: tail /etc/fstab
  2. Observa en tiempo real un archivo de registro: tail -f /var/log/syslog (presiona Ctrl+C para salir)
  3. Muestra las últimas 15 líneas de tu historial de comandos: tail -n 15 ~/.bash_history
  4. Guarda las últimas 50 líneas de un archivo en otro: tail -n 50 /var/log/apt/history.log > ultimas_actualizaciones.txt

Práctica Integrada

Ejercicios que combinan varios de los comandos aprendidos:

  1. Exploración del sistema:
    $ cd / $ ls -la > ~/exploracion.txt $ head -n 20 ~/exploracion.txt # Examina los primeros 20 resultados

    Este ejercicio te permite explorar la raíz del sistema, guardar la información y revisar los resultados.

  2. Creación y manipulación de archivos:
    $ cd ~ $ cat > practica.txt # Escribe varias líneas y presiona Ctrl+D $ cat practica.txt $ head -n 2 practica.txt > inicio.txt $ tail -n 2 practica.txt > fin.txt $ cat inicio.txt fin.txt > completo.txt $ cat completo.txt

    Aprenderás a crear archivos, extraer partes específicas y combinarlas de nuevo.

  3. Análisis de archivos del sistema:
    $ cd /etc $ ls -l | head -n 15 > ~/archivos_etc.txt $ cat ~/archivos_etc.txt # Examina los primeros 15 archivos/directorios

    Este ejercicio te familiariza con la estructura de directorios importantes del sistema.

  4. Cadena de comandos y redirecciones:
    $ ls -la /bin > comandos.txt $ wc -l < comandos.txt > resultado.txt $ echo "Total de comandos disponibles: " > informe.txt $ cat resultado.txt >> informe.txt $ cat informe.txt

    Este ejercicio te enseña a encadenar varios comandos para crear un informe sencillo.
