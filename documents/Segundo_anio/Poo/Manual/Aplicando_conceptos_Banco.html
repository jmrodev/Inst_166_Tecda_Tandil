🏦 Manual Práctico de PHP POO: Sistema Bancario (Multi-Archivo, Consola)

Preparación del Entorno y Proyecto

Este manual te guiará en la aplicación de la Programación Orientada a Objetos (POO) en PHP para construir un sistema bancario simple, estructurando el código en múltiples archivos.

Requisitos: PHP instalado, editor de texto/IDE.

Estructura del Proyecto Inicial:

  1. Crea una carpeta: sistema_bancario_poo.
  2. Dentro, crearás los archivos PHP a medida que avanzamos.

Ejecución:

  1. Para cada sección, actualiza (o crea) los archivos de clase (Cliente.php, CuentaBancaria.php, etc.) con el código proporcionado para esa sección.
  2. Luego, reemplaza completamente el contenido de tu archivo app.php con el código proporcionado en el bloque "Archivo: app.php (Script Principal - Sección N)" para la sección que estás probando.
  3. En la terminal, navega a sistema_bancario_poo/ y ejecuta php app.php.

Esto asegura que cada prueba de sección sea autocontenida y no haya conflictos por redefinición de clases.

🛡️ Sección 5: Encapsulamiento - Protegiendo los Datos del Banco

Principios del Encapsulamiento

Se usan modificadores de visibilidad: public, private, y protected. Propiedades private/protected se acceden vía getters/setters públicos.

Archivo: Cliente.php (Actualización Sección 5 - Encapsulamiento)

idCliente = $id; 
        $this->nombre = $nombre;

        } else {
            $this->email = "email_invalido@dominio.com"; 
            echo "ADVERTENCIA: Email proporcionado para cliente " . $id . " no es válido." . PHP_EOL;
        }
        $this->fechaRegistro = date("Y-m-d H:i:s");
        echo "CONSTRUCTOR: Cliente (encapsulado) creado -> ID: " . $this->idCliente . PHP_EOL;
    }

    public function getIdCliente() { return $this->idCliente; }

    public function getTelefono() { return $this->telefono; }

Un Trait (trait) permite "mezclar" (use) métodos y propiedades en clases, sin herencia. Para reutilización horizontal.

    public function retirar($monto) {
        if (!$this->estaActiva()) { /*...*/ return false; }
        if ($monto <=0) { /*...*/ return false; }
        if ($this->puedeHacerRetiro($monto)) {
            $this->saldo -= $monto;
            $this->aplicarComisionPorRetiro();
            $this->registrarEventoTrait("Retiro: -" . $this->getMoneda() . " " . number_format($monto, 2), "RETIRO");
            echo "Retiro de cta " . $this->getNumeroCuenta() . ": -" . $this->getMoneda() . " " . number_format($monto, 2) . ". Saldo: " . number_format($this->consultarSaldo(), 2) . PHP_EOL;
            return true;
        }
        echo "Error (Cta " . $this->getNumeroCuenta() . "): Retiro no permitido o saldo insuficiente." . PHP_EOL;
        return false;
    }
