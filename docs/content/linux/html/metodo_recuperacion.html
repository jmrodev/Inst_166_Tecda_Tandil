🛠️ Método de Recuperación

Si necesitas acceso físico al sistema para solucionar problemas, puedes iniciar en modo de recuperación o desde un Live CD/USB. A continuación, se explican ambos métodos:

🔧 Iniciar en Modo de Recuperación

  1. Reinicia tu computadora:

    Durante el arranque, presiona la tecla adecuada para acceder al menú de GRUB (generalmente Esc , Shift , o F12 , dependiendo de tu sistema).

  2. Selecciona el Modo de Recuperación:

    En el menú de GRUB, selecciona la opción Modo de Recuperación o Recovery Mode .

  3. Abre una terminal como root:

    Una vez en el menú de recuperación, selecciona la opción para abrir una terminal con privilegios de root.

🔧 Usar un Live CD/USB

  1. Inserta un Live CD/USB:

    Inserta un Live CD/USB de tu distribución Linux.

  2. Configura el arranque desde el dispositivo:

    Accede a la configuración de tu BIOS/UEFI y selecciona el dispositivo USB o CD como prioridad de arranque.

  3. Inicia el sistema desde el Live CD/USB:

    Una vez iniciado, abre una terminal.

  4. Monta la partición de tu sistema: 
    sudo mount /dev/sdXn /mnt

    Reemplaza /dev/sdXn con la partición donde está instalado tu sistema operativo (puedes usar lsblk para identificarla).

  5. Cambia al entorno de tu sistema: 
    sudo chroot /mnt

🔧 Realizar Cambios

Una vez que tengas acceso al sistema, puedes realizar los cambios necesarios. Por ejemplo:

  • Agregar un usuario al grupo sudo o wheel : 
    • # En Debian y derivadas:
usermod -aG sudo nombre-de-usuario

# En Arch Linux y derivadas:
usermod -aG wheel nombre-de-usuario
  • Editar el archivo /etc/sudoers con visudo : 
    • sudo visudo

🔄 Reiniciar el Sistema

  1. Sal del entorno chroot : 
    2. exit
  2. Desmonta la partición:
    3. sudo umount /mnt
  3. Reinicia el sistema:
    4. sudo reboot

✅ Conclusión

Con estos métodos, puedes acceder al sistema para solucionar problemas críticos, como permisos incorrectos o configuraciones dañadas. Asegúrate de realizar los cambios necesarios y reiniciar el sistema correctamente.
